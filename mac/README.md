# Ярлыки для Mac

Файлы `.command` можно запускать двойным кликом из Finder.

## Первый запуск

Если macOS пишет "Не удается запустить файл ... поскольку у Вас нет соответствующих прав доступа", это значит, что файлам не выданы права на запуск.

Самый простой способ:

1. Откройте Terminal.
2. Напишите `sh ` с пробелом в конце.
3. Перетащите файл `mac/разрешить запуск.sh` в окно Terminal.
4. Нажмите Enter.

Получится команда примерно такого вида:

```bash
sh /Users/имя/Downloads/tgSpamer/mac/разрешить\ запуск.sh
```

Этот скрипт сам выдаст права всем `.command` файлам и снимет блокировку macOS, если она была поставлена после скачивания архива.

После этого можно запускать двойным кликом:

- `установка.command`
- `войти acc1.command`
- `запуск acc1.command`
- `сбор участников acc1.command`
- `архивация acc1.command`

## Ручной способ

Если удобнее командами, откройте Terminal, перейдите в папку проекта и выполните:

```bash
cd ~/Downloads/tgSpamer
chmod +x mac/*.command mac/_common.sh
```

Если macOS продолжает блокировать запуск после `chmod`, снимите quarantine-флаг:

```bash
xattr -dr com.apple.quarantine .
```

После этого файлы `.command` можно открывать двойным кликом. Если macOS все равно показывает предупреждение безопасности, откройте файл через правый клик -> Open.

## Если ярлык не открывается

Из корня проекта:

```bash
./mac/"войти acc1.command"
```

Если Terminal уже открыт в папке `mac`:

```bash
./"войти acc1.command"
```

## Вход без ярлыка

Если нужно выполнить вход вообще без `.command` файла:

```bash
cd ~/Downloads/tgSpamer
npm run login:acc1
```

Для других аккаунтов замените `acc1` на `acc2` или `acc3`.

Если `node` или `npm` не найдены, запустите `установка.command` и установите Node.js LTS с открывшегося сайта.
