# Ярлыки для Mac

Файлы `.command` можно запускать двойным кликом из Finder.

Перед первым запуском на Mac нужно один раз выдать права на выполнение:

```bash
chmod +x mac/*.command
```

Если macOS блокирует запуск, откройте файл через правый клик -> Open.

Если `node` или `npm` не найдены, запустите `установка.command` и установите Node.js LTS с открывшегося сайта.
