# Telegram Sender / Parser (Android / Termux)

Проект предназначен для авторизации в Telegram, рассылки сообщений по списку, архивации диалогов и парсинга участников групп/каналов. Данная документация описывает процедуру развертывания и эксплуатации проекта в среде Android через эмулятор терминала Termux.

## 1. Требования и установка среды

**Важно:** Версия Termux из Google Play Store устарела и не поддерживается. Используйте версию из F-Droid или с официального репозитория GitHub.

1. Установите Termux.
2. Откройте терминал и обновите пакеты:
   ```bash
   pkg update && pkg upgrade -y
   ```
3. Установите необходимые зависимости:
   ```bash
   pkg install nodejs git nano dos2unix tmux -y
   ```
4. Предоставьте Termux доступ к внутренней памяти устройства:
   ```bash
   termux-setup-storage
   ```
   Подтвердите запрос в системном диалоге Android.

## 2. Подготовка проекта

1. Перенесите архив с проектом во внутреннюю память устройства (например, в папку `Download`). 
   *Примечание: перед архивацией удалите папку `node_modules` и все файлы с расширением `.bat`.*
2. Распакуйте архив в домашнюю директорию Termux:
   ```bash
   cd ~/storage/downloads
   unzip имя_архива.zip -d ~/bot
   cd ~/bot
   ```
3. Установите зависимости Node.js. Использование флага `--ignore-scripts` обязательно для предотвращения ошибок компиляции нативных модулей (например, `bufferutil`) под архитектуру ARM:
   ```bash
   npm install --ignore-scripts
   ```
4. Преобразуйте окончания строк в файлах из формата Windows (CRLF) в формат Unix (LF):
   ```bash
   dos2unix *.sh .env*
   ```
5. Назначьте права на выполнение для bash-скриптов:
   ```bash
   chmod +x *.sh
   ```

## 3. Конфигурация

Настройки профиля хранятся в файле `.env.acc1`. Если файл отсутствует, создайте его на основе шаблона:
```bash
cp example.env.acc1 .env.acc1
```
Для редактирования используйте встроенный редактор `nano`:
```bash
nano .env.acc1
```
*(Сохранение: `Ctrl+O`, `Enter`. Выход: `Ctrl+X`).*

**Ключевые параметры `.env.acc1`:**
- `SESSION_STRING`: строка сессии. Заполняется автоматически после успешной авторизации.
- `LIST_FILE`: имя файла со списком получателей из директории `lists/`.
- `MESSAGE_FILES`: имя файла с текстом рассылки из директории `messages/`.
- `SOCKS_PROXY` и `SOCKS_TYPE`: параметры прокси-сервера. Если локальный прокси на устройстве не настроен, закомментируйте эти строки символом `#`, иначе подключение к Telegram будет заблокировано.
- `STORAGE_MODE`: `shared` (общее хранилище) или `per_profile` (изолированное хранилище в `storage/acc1/`).

## 4. Эксплуатация

### 4.1. Использование bash-скриптов
Вместо Windows-скриптов `.bat` в Termux используются файлы `.sh`.

- **Авторизация (первый запуск):**
  ```bash
  ./login_acc1.sh
  ```
  Отсканируйте сгенерированный QR-код через настройки Telegram (Устройства -> Подключить устройство).

- **Запуск рассылки:**
  ```bash
  ./start_acc1.sh
  ```

- **Архивация диалогов:**
  ```bash
  ./archive_acc1.sh
  ```

- **Парсинг участников:**
  ```bash
  ./parse_acc1.sh
  ```

### 4.2. Прямой вызов через npm
Альтернативный способ запуска из корневой директории проекта:
- Авторизация: `npm run login:acc1`
- Рассылка: `npm run start:acc1`
- Архивация: `npm run archive:acc1`
- Парсинг: `npm run parse:acc1` (или `npm run parse:acc1 -- @username` для пропуска интерактивного выбора)
- Планировщик: `npm run schedule:acc1`

## 5. Фоновая работа и стабильность

Операционная система Android агрессивно завершает фоновые процессы. Для обеспечения непрерывной работы необходимо:

1. Отключить оптимизацию батареи для приложения Termux в системных настройках Android (Настройки -> Приложения -> Termux -> Батарея -> Без ограничений).
2. Закрепить приложение в меню недавних задач (свайп вниз по иконке или значок замка).
3. Использовать мультиплексор терминалов `tmux` для изоляции процесса от сворачивания терминала:
   ```bash
   tmux new -s tg_bot
   ./start_acc1.sh
   ```
   Для отключения от сессии без остановки процесса нажмите комбинацию клавиш `Ctrl+B`, отпустите, затем нажмите `D`. 
   Для возврата к сессии выполните: `tmux attach -t tg_bot`.

## 6. Структура данных

- `lists/`: текстовые файлы со списками пользователей и результаты работы парсера.
- `messages/`: текстовые файлы с шаблонами сообщений.
- `storage/` (или `storage/acc1/` при `STORAGE_MODE=per_profile`): файлы состояния прогресса (`progress-state.json`), обработанные пользователи (`processed-users.json`), дневная статистика и логи.
- `report.csv`: итоговый отчет о рассылке.

*Для полного сброса прогресса рассылки удалите файлы `progress-state.json` и `processed-users.json` из соответствующей директории `storage/`.*
